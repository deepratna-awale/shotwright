LTX responds best to a single flowing paragraph under 200 words, written chronologically. Start directly with the main action in one sentence, then character appearance, background and environment, camera angle and movement, lighting and colour, and any sounds, in the order they matter. If there is a style, begin with "Style: ..." in one short sentence. Write like a cinematographer describing a take. For image-to-video, describe only what changes from the starting image (motion, camera and sound); models that ask for the first frame to be described get that description first, then the change. Avoid lists and on-screen text.
